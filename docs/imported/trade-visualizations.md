# EU4 Trade Income — Visualization Design

Three complementary views, meant to be used together: an overview, a
per-node detail, and an interactive experimentation tool.

---

## 1. Trade Network View — Sankey Diagram

**Purpose:** show the whole in-range trade network at a glance — where
money originates and where it flows.

**Encoding:**
- **Nodes** = trade nodes reachable from the player's home node (out-of-range
  nodes hidden or shown collapsed/greyed at the edges for context).
- **Edge width** = trade value flowing from one node to the next.
- **Node fill/border color** = the player's power share in that node
  (color scale, e.g., light → dark as share increases), with a small
  inset ring or pie showing your share vs. rivals vs. "other."
- **Node badge** = merchant icon if a merchant is currently assigned there,
  with a small arrow glyph indicating steering direction when applicable.

**Interaction:**
- Hover a node → tooltip with total value, your power, your share, ducats
  collected/forgone.
- Click a node → opens the per-node breakdown (View 2) for that node.
- Toggle between "Snapshot," "Optimal," and any named manual capture to see
  the network re-flow (edge widths and node colors animate to the new state).

---

## 2. Per-Node Breakdown — Waterfall / Stacked Bar

**Purpose:** explain *why* a node produces the income it does, step by step.

**Encoding (sequential bars, left to right):**
1. **Local value** — value produced within the node
2. **+ Incoming value** — value received from upstream nodes (can be
   sub-segmented by contributing upstream node)
3. **= Total node value**
4. **Power split** — stacked bar: your power / rival powers / "other," from
   which your **share %** is derived
5. **→ Outcome** — either:
   - **Collect:** `value × share` shown as ducats gained (highlighted)
   - **Steer:** value redirected downstream, shown as an arrow feeding
     into a shadow bar on the target node (ducats gained = 0 here, "value
     deferred" annotation instead)

**Comparison mode:** show two waterfalls side-by-side (or overlaid with
different opacity) for **Collect vs. Steer** at this node, so the delta is
immediately visible — this directly answers "should I steer or collect
here?"

**Interaction:** every bar segment is annotated with the exact modifier
contributing to it (e.g., "+3.2 trade power: 2 light ships," "+1.5:
merchant presence") so the breakdown doubles as an explanation of the
underlying mechanics.

---

## 3. What-If Calculator — Interactive Panel

**Purpose:** let the user experiment with merchant/ship assignments and see
the resulting income live, without needing to touch the actual save file.

**Controls:**
- Node selector (or apply globally)
- Per node: merchant present (on/off), action (collect / steer + target
  picker), ships assigned (stepper or slider)
- Global: preset selector — **Snapshot / Optimal / [named manual captures]**
- "Capture this configuration" → prompts for a name, stores the current
  slider/picker state as a new named preset

**Output (live-updating, drives Views 1 & 2):**
- Total monthly trade ducats
- Per-node ducats table (sortable)
- Delta vs. Snapshot and vs. Optimal, shown as `+X ducats/mo` badges, so
  the user immediately sees how their manual tweak compares

**Relationship to the optimizer:** the "Optimal" preset is generated by the
algorithm in `trade-income-calculation.md` §6 and is just another entry in
the same preset list as "Snapshot" and any manual captures — the UI treats
all three uniformly (see the web-app doc's data model for `TradeConfiguration`).

---

## How the three views combine on screen

```
┌─────────────────────────────────────────────┐
│  Preset selector: [Snapshot] [Optimal] [My Plan ▾]   │
├─────────────────────────────┬─────────────────────────┤
│                               │                         │
│      Sankey network view      │   What-If calculator    │
│      (click node to focus)    │   (sliders/pickers)     │
│                               │                         │
├───────────────────────────────┴─────────────────────────┤
│         Per-node breakdown (waterfall) for selected node  │
└───────────────────────────────────────────────────────────┘
```

Selecting a node in the Sankey drives the waterfall below it; changing any
control in the calculator re-flows the Sankey and updates the waterfall —
all three views always reflect the same currently-selected preset/state.
