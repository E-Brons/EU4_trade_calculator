## Verified facts from response_1 (do not contradict, do not re-ask)

- `prev(country, B) = sum over downstream nodes D of trunc3(province_power_D / 5)`, only for D with the country's `province_power_D >= ~10` (largest non-propagating value 9.961, smallest propagating 10.036; `>` vs `>=` at exactly 10.000 untestable). - In the 78 start snapshots a link B->D propagates exactly when the node's recorded `steer_power` weight for that link at B is > 0 (109,487 of 109,487 with this gate, 106,377 without). Example: S14 `california` `steer_power={ 0.0 1.0 0.0 0.0 }` (links mexico, mississippi_river, girin, polynesia_node): XAL has `province_power=11.31` at mexico and at california only `province_power=0.87 max_pow=0.87` (no `prev`). (C-Q3.1)
- In the played saves (S79, S80 and their copies) the gate does not hold: single-link cases 1,836: weight > 0 and propagated 1,636; weight 0 and propagated 182; weight 0 and not propagated 18; weight > 0 and not propagated 0. Gate explains 3,796 of 4,072 candidates, the plain threshold rule 4,044. Example S80 `california` `steer_power={0.885 0.114 0.0 0.0}` yet entries propagate over the link to girin (weight 0). (C-Q3.2)
- MOR in S80: `prev` is higher than the rule by 0.25 x (downstream `ship_power`) / 5: kongo 10.797 vs 10.272 (ivory_coast `ship_power=10.5 light_ship=3`, province_power 51.36), katsina 12.305 vs 11.78 (tunis ship_power 10.5), cape_of_good_hope and brazil 10.797 vs 10.272, timbuktu 14.216 vs 13.341 (= (safi 7.0 + ivory_coast 10.5) x 0.05). 460 of 460 MOR candidates (all 82 saves: 426 snapshot + 34 played) match with the term, 450 without; one country in one game (S80 = U01), so the term is a fit (`inferred`), not a rule; the factor 0.25 is fitted from three distinct sums (10.5, 10.5, 17.5). Non-MOR entries with downstream ship power in the played saves (S79 267, S80 232) are all explained without any ship term. The 78 start saves have no downstream ship power at all. (C-Q3.3)
- The save has no string `ship_power_propagation`, `propagat` or `caravan` in the S80 gamestate; the MOR country block has `active_idea_groups` (MOR_ideas 7, ...) and `modifier` entries.
