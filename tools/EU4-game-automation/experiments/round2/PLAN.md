# Round 2 - plan (offline design, 2026-10-07)

Every open row of `docs/research/R*_request_2.md` with its decision:
**(a)** a round-2 job answers it (jobs below), **(b)** answerable from saves we have or will have (existing corpus /
round-1 `experiments/out/` / the diversity batch `experiments/diversity/out/obs-<year>-<TAG>/{A,C}`) or from the game
files, **(c)** not answerable by saves or automation (reason given).
Finals R02, R03, R12 have no open rows; R02's request_2 still lists side rows (below).

Generated by `make_round2.py`; checked by `validate_round2.py` (all JSON parse, all files exist except the two NED 1618
bases the diversity batch writes, effect keywords exist in the game scripts or, for engine-only effects
`add_idea`, `add_idea_group`, `add_to_trade_company`, in the binary, every patch runs on its real base and changes only
what it should). `prep_bases.py` extracts the U10 base from `datasets/` (run once). Run:
`python3 tools/EU4-game-automation/experiments/run_all.py --dir tools/EU4-game-automation/experiments/round2`.

Game-file facts found while designing (answer rows directly, `common/defines.lua` 1.37.5, lines 1195-1220):
`TRADE_MERCHANT_PRESENT = 0.1 -- bonus on income if trade present` (R07 row 1), `EMBARGO_BASE_EFFICIENCY = 0.5`,
`EMBARGO_MERCANTILISM_EFFICIENCY = 50` (R01 row 4, R10 row 4), `PIRATES_TRADE_POWER_FACTOR = 1.5`,
`PIRATES_MONOPOLY_BONUS = 1`, `PRIVATEER_INCOME_COLLECTION_EFF = 0.5` (R10 rows 1-2), `TRADE_PROPAGATE_DIVIDER = 5`,
`TRADE_PROPAGATE_THRESHOLD = 2` (R05: the gate is province_power / 5 vs 2), `TRADE_CAPITAL_POWER = 5.0`,
`TRADE_ADDED_VALUE_MODIFER = 0.05` (R08 row 5 candidate), `PO_TRADE_POWER_AMOUNT = 0.5 -- Transfer 50% of trade power on
peace option` (R04 row 3). `common/subject_types/00_subject_types.txt`: `transfer_trade_power = yes` only for colony,
eyalet, commercial_enterprise, trade_protectorate (why E20a/b/d vassal/march/union showed no transfer); tributary needs
the overlord flag `forced_tributary_state` or `can_create_tributaries_flag` (why E20c created nothing).
Saves: a transfer is the diplomacy relation `transfer_trade_power={ amount=... is_enforced=yes first second start_date }`;
U25: LDU -> MRA `amount=1.000` (the 1.0 givers), U04: 24 relations, all `amount=0.500` (colonies, trade protectorates)
-> R04 row 4 (what sets the fraction) is answered by the saves: the relation's `amount`. `samoan_ideas`:
`global_ship_trade_power = 0.2` (R11 row 2: f = 1.2 for SAM confirmed); `MOR_ideas` has no ship-trade modifier
(R05 row 3 stays open). Embargo in saves: embargoer `trade_embargoes={ TAG }`, target `trade_embargoed_by={ TAG }`.
